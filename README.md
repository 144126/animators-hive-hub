# animators hive hub

sveltekit + cloudflare + supabase. showcase animations, communities, playlists.

```sh
pnpm i
cp .env.example .env   # PUBLIC_SUPABASE_URL + PUBLIC_SUPABASE_PUBLISHABLE_KEY
pnpm dev               # :8080
pnpm build
```

old `VITE_SUPABASE_*` names still work as public aliases.
